## 🚀 Live Preview & Quick Start
Open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Brave, Firefox, Safari) or double-click `index.html` in your file explorer.

### Deploy to GitHub Pages (1-Click Hosting):
Since this workspace is a Git repository:
```bash
git add .
git commit -m "feat: initial release of Mohamed Baheed interactive portfolio"
git push origin main
```
Then go to your GitHub repository **Settings > Pages > Branch: main / root** and click **Save**. Your portfolio will be live on the web instantly at `https://mdbaheed.github.io/gitgithub/`!

## MANGANEX Prototype

The manganese project card opens `manganese-prototype.html`, which includes the supplied demo recording, the source archive, and local run instructions. MANGANEX is a React/TypeScript dashboard backed by a FastAPI service. Its exploration and production datasets are synthetic; model scores are not evidence of actual deposits or production outcomes.

The supplied `Manganex-01 Demo.mp4` is larger than GitHub's 100 MB per-file limit. To publish the recording, use Git LFS or host it separately and update the video URL in `manganese-prototype.html`. The portfolio itself can still be published without the recording.

## 🎨 Design Philosophy
- **Aesthetic:** Cyber-luxe dark mode with neon cyan, violet, and emerald gradients.
- **Glassmorphism:** High-performance backdrop-filter cards with glowing borders.
- **Audio:** Built-in Web Audio API synthesizer for tactile UI clicks (with instant mute toggle).
- **Mobile Responsive:** Adapts to all devices from ultra-wide displays down to smartphones.
