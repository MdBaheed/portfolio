⚠

Run the interactive dashboard locally

Extract manganex-1.zip into the portfolio folder so it creates a manganex\ folder beside this page. The frontend and API must run in separate terminals; the frontend proxies API requests to the backend on port 8000.

1. Start the backend (PowerShell)

cd .\manganex\backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

2. Start the frontend (new terminal)

cd .\manganex\frontend
npm install
npm run dev

Then open http://localhost:5173. The backend API documentation is available at http://localhost:8000/docs. The models train on startup using the bundled synthetic datasets.
